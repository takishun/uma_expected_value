# 馬券バリューチェッカー

オッズ・出走頭数・掛け金を入力すると、馬券の種類ごとに期待値と「妙味（オッズが
理論値より割安かどうか）」を計算するStreamlitアプリです。

## 起動方法

```bash
pip install -r requirements.txt
streamlit run oz_cal.py
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `oz_cal.py` | Streamlitアプリのエントリポイント（画面の組み立て） |
| `baken.py` | 的中確率・期待値の計算（UI非依存・標準ライブラリのみ） |
| `affiliates.py` | アフィリエイト広告の定義と描画 |
| `theme.py` | スマートフォン向けレイアウトの配色とスタイル |
| `.streamlit/config.toml` | Streamlitのテーマ設定（`theme.py`と対応） |
| `design/` | レイアウト提案のモックアップ（HTML） |
| `tests/` | pytestによるテスト |

## 画面レイアウト

スマートフォンを基準に組んでいます（`design/mobile-layout-proposals.html` の案A
「オッズ掲示板」を採用）。

- 式別を期待回収率の高い順に、1行1枚のカードとして縦に並べます。
  カード下部のバーは期待回収率を表し、中央の縦線が100%（損益分岐）です。
- オッズ・頭数・掛け金の入力欄は画面上部に固定され、一覧をスクロールしても
  そのまま操作できます。
- 競馬場のオッズ表示板に合わせたダーク基調で、数値は等幅フォントで桁を揃えます。

## 計算の前提

「全馬の実力が互角で、着順は完全にランダム」と仮定し、買い目の組み合わせの数から
1点あたりの的中確率を求めています。

```
的中確率   = 的中する組み合わせの数 / 全組み合わせの数
期待値     = 掛け金 × オッズ × 的中確率
損益分岐オッズ = 100 / 的中確率(%)      … 期待値が掛け金と等しくなるオッズ
期待回収率  = オッズ × 的中確率(%)       … 100%を超えると妙味あり
```

式別ごとの扱いは次のとおりです。

| 式別 | 的中する組み合わせ | 全組み合わせ | 発売される最小頭数 |
| --- | --- | --- | --- |
| 単勝 | 1 | n | 2 |
| 複勝 | 2着まで（7頭以下）/ 3着まで（8頭以上） | n | 5 |
| 三連単 | 1 | P(n, 3) | 4 |
| 三連複 | 1 | C(n, 3) | 4 |
| 馬単 | 1 | P(n, 2) | 3 |
| 馬連 | 1 | C(n, 2) | 3 |
| ワイド | C(3, 2) = 3 | C(n, 2) | 4 |
| 枠連 | 1 | 枠の組み合わせ数（ゾロ目を含む） | 9 |

枠連は、JRAの8つの枠に出走頭数を割り振ったうえで買い目の数を数えます。9頭以上の
レースでは端数が8枠側から順に割り当てられ（18頭なら 2,2,2,2,2,2,3,3）、同じ枠の
2頭が1着2着を占める「ゾロ目」も買い目に含めています。

馬の能力・馬場・距離・天候などは一切考慮していないため、あくまで参考値です。
